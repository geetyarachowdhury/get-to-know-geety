# Geety portfolio

A build-free portfolio using HTML, CSS and JavaScript.

## Open locally
Open `index.html` in your browser. Keep all three code files together. An internet connection loads the Google Fonts; system fonts serve as fallbacks.

## Upload to GitHub Pages
Upload index.html, style.css and script.js to the repository root. In repository Settings → Pages, select Deploy from a branch, then main and / (root).

## Customize
- Main content: index.html
- Accent color: --maroon in style.css (currently #800020)
- Case study descriptions and interactions: script.js
- Playground: replace the commented placeholder article in index.html; add case details in script.js only if using an interactive card.

Client and internal project names are omitted. Contact links remain pending from the original version; add your verified contact details before using this for applications.

## Digital art
The six original PNG files are in assets/art/. Upload that folder alongside the three code files. Do not rename it without updating the paths in index.html. Frames are CSS only; artwork remains uncropped. Select a frame to enlarge it; use Previous/Next or the left/right arrow keys, and Escape to close. Instagram links to https://www.instagram.com/geety.art/.

Artwork titles: Leap of Faith, Emergence, Retro Crush (provided by Geety); Afternoon Indulgence, A Little Sweetness, Sunshine Slice (suggested titles).
